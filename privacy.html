Privacy Policy

Clip Studio Clock · Effective 14 November 2026

Clip Studio Clock is a private program used only by the owner of the Clip Studio Gaming YouTube channel, on their own computer. It is not offered to the public.

Google user data it accesses

With the channel owner's consent, it requests two read-only permissions:

  • View your YouTube account (youtube.readonly): used only to read the channel's total view count.
  • View YouTube Analytics reports (yt-analytics.readonly): used only to read the channel's views by country for the last 7 reported days, to work out the share from the United States and Canada.

How it uses that data

The numbers are shown on a pixel clock on the owner's local network. Nothing else is done with them.

Where it is stored

Only on the owner's computer: the Google sign-in token, the latest totals, and today's starting count. Nothing is sent to any server other than Google's own APIs and the clock on the owner's home network.

Sharing

Google user data is not sold, shared, transferred or disclosed to anyone, and is not used for advertising. Clip Studio Clock's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the program's folder removes all stored data.
